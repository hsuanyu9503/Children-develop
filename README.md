# 兒童發展複習網站 v2.3｜馬卡龍風格

此版本使用正式指定的第一種「馬卡龍感」設計：粉紅、淡紫、天空藍、薄荷綠、柔和圓角與舒適間距。

## 使用方式
- 直接開啟 `index.html`，或將檔案部署到 GitHub Pages。
- 題目與筆記已內建於 `index.html`，不需要連線取得題庫。
- 包含 10 個章節群組；270 題歷屆選擇題、62 題歷屆非選擇／綜合題，以及 18 題自編練習。
- 可以勾選多個章節進行複習，錯題與學習紀錄儲存在目前使用的瀏覽器。
- 請注意：部分歷屆題目尚未完成課堂章節對照，仍可透過「全部章節」或「考點主題」練習。

## 更新說明
- v2.3 僅調整網站視覺、深色模式一致性與閱讀對比；保留 v2.0 題庫及測驗邏輯。
- 若要在 GitHub Pages 更新，只要以新版 `index.html` 覆蓋同名檔案即可。
