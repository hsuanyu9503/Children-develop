# 兒童發展｜期中考複習網站 v1.0

五章範圍：第一章「人類發展的研究」、第二章「理論與研究」、第三章「新生命的形成」、第四章「三歲前的生理發展」、第五章「三歲前的認知發展」。

## 使用方式

- 下載 ZIP 後解壓縮，開啟 `index.html` 即可在多數桌上型瀏覽器使用；或將解壓縮後的所有檔案放到 GitHub Pages 儲存庫根目錄，上傳後網站會直接讀取靜態 JS 資料。
- **本版不需 Supabase、不需 API、不使用外部 CDN。** 手機瀏覽器也可操作。
- 已讀、選擇題紀錄、收藏與申論草稿寫入該瀏覽器 `localStorage`；圖片筆記由使用者選擇原圖後寫入 `IndexedDB`。跨裝置請到「資料與設定」匯出 JSON，再到另一裝置匯入。
- 若從裝置開啟 `file://`，部分手機瀏覽器可能限制本機儲存或圖片匯入；放到 GitHub Pages 後通常更穩定。

## 目前版本包含

- 第一至第五章：38 個概念筆記（依老師的原始投影片與課程學習資料整理，**不是之前逐字定稿文字稿**）。
- 第 106～115 年歷屆試卷中初步篩選出與前五章相關的 62 題選擇題（附官方公布選擇題答案）、18 題**自編課堂練習（非考古題）**、6 題相關申論題。
- 圖卡庫：42 個依據目前章節概念預留的圖卡主題位置（不代表原有已定稿圖卡的精確張數或標題；第三、四章拆開顯示）；**原本完成的圖片檔尚未取得**，請在圖片筆記庫逐張匯入原圖，不會把空白位置或新圖當成定稿。
- 練習、模擬測驗、錯題重做、收藏、已讀進度、申論草稿與 JSON 匯入／匯出。

## 來源與校對狀態

- 章節順序及內容依據：`第一章及教師檢定考試.pptx`、`第二章理論與研究.pptx`、`第四章三歲前的生理發展.pptx`（其前幾頁含第三章「新生命的形成」）、`第五章三歲前的認知發展.pptx`、第一、二、三四、五章學習單 PDF。
- 歷屆考題依既有「兒童發展_考古題網站資料草案.json」初步索引篩選；答案已對應原先的官方選擇題參考答案，但**PDF 題文尚未完成逐題人工複核**。
- 第三章缺乏適合且可明確對應的既有歷屆選擇題，因此先提供 3 題明確標註的自編練習。
- 歷史醫療統計與具時效性的法規不混作本版現行資訊，也不納入期中題庫。

## 日後擴充第六至第十章

在 `data/chapters.js` 新增章節、`data/notes.js` 新增筆記、`data/questions.js` 新增對應 `chapter` 的練習題、`data/gallery.js` 新增圖卡位置即可。**既有題目 `id` 請保持不變**，以免學習紀錄遺失。頁面會自動根據資料產生導覽，不需重寫整套系統。

編輯 JS 資料檔請使用 UTF-8 編碼。更新前建議先使用網站中的「匯出學習紀錄」。
