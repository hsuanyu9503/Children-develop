## 部署 GitHub Pages

上傳 ZIP 解壓後內容（`index.html`、`data/`、`assets/`、`README.md`）到儲存庫**根目錄**。在 Settings → Pages → Deploy from a branch 中選 `main`/`root`。

若在 iPad GitHub 網頁無法上傳資料夾，可依序進入 `assets` 及 `assets/thumbs` 資料夾，使用 Upload files 逐批上傳所含檔案；或在電腦上解壓並整個資料夾上傳。只上傳 ZIP 本身不能部署成網站。
