# 兒童發展｜期中複習網站 v1.0.1（題庫載入修正版）

## 這次修正

- 修復 v1.0 在部分開啟方式下，分離的 `data/questions.js` 沒有成功載入、導致首頁顯示 0 題的問題。
- **目前 `index.html` 已內建完整 CSS、程式與題目資料**，可單獨使用，也可以單獨放到 GitHub Pages 儲存庫。
- 第一至第五章共有 80 題可練習選擇題（62 題歷屆題目、18 題標註為自編的練習題）。另有 6 題申論練習。

## 立即使用

**最簡單方式：**直接下載 `兒童發展_期中複習網站_v1.0.1.html`，以 Safari、Chrome、Edge 開啟，首頁「可練習題目」應該顯示 **80 題**。點選「題庫練習」→「開始出題」即可作答。

**GitHub Pages：**只上傳本 ZIP 根目錄的 `index.html` 就可以運作；不再依賴其他 `data` 檔案的路徑。如 GitHub Pages 仍載入舊檔，請強制重新整理或使用無痕視窗。

**iPad / iPhone：**若在「檔案」App 的預覽視窗開啟，該預覽可能不允許互動 JavaScript；建議部署至 GitHub Pages 再以 Safari 開啟。

## 學習紀錄

網站以瀏覽器 localStorage 儲存進度、答題紀錄與收藏；圖片另外儲存在 IndexedDB。裝置檔案預覽模式可能禁止本機儲存，這時可正常練題，但退出後未必保留紀錄。正式長期使用建議透過 GitHub Pages；也可以在「資料與設定」手動匯出備份。

## 校對提醒

考古題依官方選擇題參考答案配對，PDF 文字擷取仍待逐題核對；請不要把本版提示當成經完全校對的官方解析。自編題則不屬於歷屆試題。

## 更新資料的方法

`source/data/*.js` 是擴充的原始資料。資料更新後，要重新將 CSS、JS 及資料整合進 `index.html`，才能維持單檔可靠載入的特性。只更新 `source` 不會直接影響現有單檔網站。
